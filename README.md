One fortune cookie line for a crypto trader who has just been liquidated, written for make.fun's "Fortune Cookie for the Liquidated Trader" bounty. A judge playing the freshly liquidated trader reads fortunes two at a time and keeps the one that earns a laugh rather than a tear.

The entry (15 words):

> Your lucky numbers are 0, 0, 0, 0, and 0. Your liquidated portfolio chose them.

It keeps the classic fortune-cookie voice — lucky numbers — and lets the punchline land on the loss: the portfolio is at zero, so zero is the only lucky number it has left.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22) prints the fortune, validates it against the gate (one line, 1–160 characters, at most 20 words), and writes the identical text to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
